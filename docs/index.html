MacLister

A lister-based file manager for macOS in the spirit of Directory Opus Magellan. Double-click the empty desktop and a lister opens right where you clicked. Menedżer plików z listerami dla macOS w duchu Directory Opus Magellan. Dwuklik na pustym pulpicie otwiera lister dokładnie tam, gdzie kliknąłeś.

Install in a minuteInstalacja w minutę

MacLister is ad-hoc signed, not notarized by Apple (that needs a paid developer account), so macOS asks you once. MacLister jest podpisany lokalnie i nie przeszedł notaryzacji Apple (wymaga płatnego konta programisty), więc macOS zapyta Cię raz.

  1. Download MacLister-<version>-macos.zip from the latest release, unzip it and drag MacLister.app to /Applications. Pobierz MacLister-<wersja>-macos.zip z najnowszego wydania, rozpakuj i przeciągnij MacLister.app do /Applications.
  2. First launch: Control-click the app and choose Open, then Open again. Pierwsze uruchomienie: kliknij aplikację z Control i wybierz Otwórz, potem jeszcze raz Otwórz.
  3. In System Settings → Privacy & Security allow Accessibility and Input Monitoring (needed to notice a double-click on the desktop), then quit and start MacLister again. W Ustawieniach systemowych → Prywatność i ochrona zezwól na Dostępność i Monitorowanie wprowadzania (potrzebne do wykrycia dwukliku na pulpicie), potem zamknij MacListera i uruchom go ponownie.
  4. Double-click an empty spot on the desktop. Updates: Check for Updates… in the menu-bar menu (automatic checks are off unless you turn them on). Kliknij dwukrotnie puste miejsce na pulpicie. Aktualizacje: Sprawdź aktualizacje… w menu paska menu (sprawdzanie automatyczne jest domyślnie wyłączone).
